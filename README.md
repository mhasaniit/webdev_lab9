# Web Development Lab 9

## Overview
This is Lab 9 for ITMD-361. In this lab, I worked with basic JavaScript and implemented it into a live web page. The goal was to understand how JavaScript interacts with HTML to add simple interactivity to a website.

## Features
- Added basic JavaScript functionality to a web page
- Integrated JavaScript with HTML structure
- Enabled simple interactive behavior on a live site
- Practiced connecting front-end components (HTML, CSS, JavaScript)

## Tools Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub (for version control and submission)

## Learning Outcomes
- Learned how JavaScript enhances web pages with interactivity
- Understood how to connect JavaScript with HTML elements
- Gained experience implementing basic client-side scripting
- Strengthened foundational front-end development skills

## Purpose
The purpose of this lab was to introduce JavaScript integration into web pages and demonstrate how scripting can improve user interaction on a website.
